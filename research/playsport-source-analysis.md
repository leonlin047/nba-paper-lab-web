# 玩運彩 NBA 盤口來源分析（2026-10-24）

來源：https://www.playsport.cc/predict/games?allianceid=3

## 公開網頁已觀察欄位
- NBA 場次編號、開賽時間、主客隊。
- 國際盤：讓分（可能含半輸半贏）、大小。
- 台灣運彩盤：讓分/受讓、獨贏、大小及十進位賠率。
- 歷史球隊頁：歷史結果、讓分盤及過盤率。
- 預測比例頁：使用者預測比例及人數；不是實際勝率或模型預測。

## 上游來源結論
- 網站顯示「國際盤」「運彩盤」，但公開頁面不足以判定國際盤由哪一家莊家或供應商提供。
- 台灣運彩欄位可與台灣運彩官方盤口逐場核對；不能在沒有證據時聲稱直接來自官方 API。
- 玩家預測比例為站內使用者選擇分布，非博彩賠率、模型預測或歷史實際勝率。

## 對接技術
- 建立獨立來源適配器：抓取公開 HTML，辨識日期、對戰、場次編號、盤口類型、方向、讓分值、賠率、擷取時間。
- 以台灣時間和主客隊對照 ESPN event ID；不可僅靠賽事序號。
- 保存來源、時間與完整性狀態，拒絕缺少雙方賠率或歧義讓分方向的資料。
- 將國際盤、台灣運彩盤及 ESPN/DraftKings 作不同來源，不得混合為同一個盤口。
- 半輸半贏屬亞洲盤型，結算規則需獨立處理。
- 資料擷取前審核網站條款與授權。網站頁腳載明「轉載或侵害必究」，不應將頁面全文鏡像發布，也不可繞過登入、驗證碼或存取控制。
