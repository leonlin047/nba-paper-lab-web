# NBA Paper Lab — 分析師版資料證據與模型驗證（2026-10-24）

## 1. 來源可信度與現在的實際覆蓋

| 來源 | 已實作證據 | 用途 | 不得推論的事情 |
|---|---|---|---|
| ESPN scoreboard + 2016–17 至 2025–26 歷史賽果 | 12,815 場已完成比賽，時間與主客隊、得分；目前約 2–3 週賽程 | 長期 Elo、逐場得失分、主客、休息、交手、時序回測 | 沒有隊伍失分就說防守效率、以比賽日期推定真實飛行時程 |
| ESPN game summary/boxscore | 已驗證團隊 FGA、FGM、3PA、3PM、FTA、OREB、DREB、TO；近況擷取上限 45 場 | eFG%、三分出手率、失誤／估算回合、團隊出賽紀錄 | 估算回合數並非 NBA 官方 Pace；沒有 boxscore 就不得補數 |
| ESPN NBA injuries | 球員與隊伍代碼、傷病狀態、通報日期；不同場次須以擷取時間為準 | 賽前不確定性標示、出賽資訊風險 | Out/GTD 文字並非保證上場時間；沒有球員 on/off 模型就不調整機率 |
| PBP Stats 官方 API | 已測試 `/get-pace-efficiency-summary/nba`，2025–26 常規賽 30 隊 `ppp`、`spp` | 前季每回合得分與進攻速度參照（每日最多刷新一次） | 前季資料不能稱為本季即時節奏；2026 夏季異動需要另查 |
| ESPN summary pickcenter / 國際盤 | 部分賽事讓分、獨贏、總分，帶供應商與快照擷取時間；亦有業者「開盤／目前」標記 | 比較相同賽事三種玩法與市場機率 | 業者標記開／目前不具每次異動的時間戳；不能猜測莊家資金或動機 |
| ESPN NBA News API | 署名、標題、刊登時間、相關隊伍及來源 URL | 賽事背景、供人工核對傷病及陣容變化 | 新聞標題和隊伍標籤不能當成先發名單或數值模型輸入 |
| NBA 官方傷病公告 | 官方參考路徑 `https://official.nba.com/nba-injury-report-2026-27-season/` | 需要與 ESPN 交叉確認的高優先級來源 | 目前沒有已驗收的逐場官方名單自動解析器 |
| X 記者清單 | 來源連結與分類，**未接通 X API** | 追蹤 Shams Charania、Marc Stein、各隊公關等可核對消息 | 不能自稱已自動監測即時發文；傳聞不能直接改勝率 |
| 台灣運彩 / JBot | JBot API 介面及私有研究解析器已建；需要合法金鑰和授權 | 台灣盤初／即時／收盤、歷史價格 | 未授權之前不能稱為已接通 |
| 玩運彩 | 公開 NBA 賽事網頁實測可讀；私人研究已有 HTML 結構解析器 | 以不同公開展示來源進行來源差異研究 | 賽後爬取不能回填為賽前價格；對外展示與排程需遵循使用條款 |
| The Odds API | `basketball_nba` 的歷史盤口 API 文件已核對 | 國際盤商多源、歷史快照與收盤線 | 歷史端點需付費；早期數據不涵蓋所有十年季別 |

## 2. 每場比賽實際檢查的因素

- **獨贏**：十季固定參數 Elo 先前逐場贏球機率；主場優勢已列入 Elo；主隊／客隊過去 12 場得失分及淨勝分、主客拆分、雙方最多 4 次交手。
- **讓分與受讓**：必須有可驗證實際主／客讓分線。比分分差模型以歷史真實比賽結果估計分差分布，常態殘差的 sigma 在 2022–23 至 2024–25 訓練期間估算，2025–26 只評估，不在驗證期間偷看未來。整數線走水仍未獨立建模。
- **大小分**：各隊近 12 場進攻／防守得分平均，考慮實際主場平均差；年度聯盟基準與季節變化；歷史總分殘差的 sigma；近期 eFG、三分出手率、TO% 與 estimated possessions；前季 PBP PPP／SPP 僅為歷史輔證，未調權進入比分模型。
- **疲勞**：最近完賽至預定開賽的間隔；36 小時內標記近似背靠背；超過 14 天視為休賽季缺口，**不**當作賽前休息天數。
- **傷病**：只接受擷取時間早於該場開賽、與正確隊伍代碼對應的通報。若數據過期或缺失，明示無法量化，絕不憑「某人缺陣」即計算勝率加成。
- **新聞與社群**：新聞日期與賽事日期需在同一場開賽前，隊伍可對應；連到原文供核對。X 目前只存來源清單，不假設有即時貼文。
- **市場變動**：莊家名稱、玩法、隊伍、方向、線、開／目前欄位、觀察時間；若缺逐筆時間，不能將事後市場資訊當作賽前可知特徵。

## 3. 現行校準與試驗結果

- 2016–17 至 2025–26：12,815 場真實已完賽事件（歷史賽果完整性已稽核）。
- 獨贏十季 Elo：2025–26 賽季 1,316 場按時間逐場驗證；Brier 與 Log loss 另見 `data/research.json`。
- 分差與總分：2022–23 至 2024–25 賽季的比賽比分用於估計殘差 sigma 與 Elo／近期攻守權重，2025–26 為獨立按時序檢驗集。見 `data/analyst_validation.json` 的 MAE、RMSE、樣本數、簡單基準與 paired bootstrap CI。
- 若混合比分模型不如純 Elo，需**明示**，不准寫「勝率提升」。總分 MAE 改善不代表歷史大分／小分過盤率改善。
- 讓分、大小分市場要完成真正的 ATS／O-U 校準，必須有真實且包含賽前擷取時間的歷史盤口。不可拿 ESPN 網頁事後的 open/close 欄位假裝當時已知。

## 4. 進階資料源驗證候選

- [NBA 官方技術統計定義](https://www.nba.com/stats/help/glossary)：Pace、OffRtg、DefRtg、eFG%、TOV%、OREB%。
- [PBP Stats API docs](https://api.pbpstats.com/docs)：有實際 documented `get-pace-efficiency-summary`、`get-four-factor-on-off`、`get-game-logs`、`get-possessions`，需審核額度與使用權後再擴充。當前只接入前季 PPP／SPP。
- [The Odds API historical odds](https://the-odds-api.com/historical-odds-data/)：公開文件表明歷史快照從 2020 年起，並且屬付費權限；不能假定擁有 2016 年以來的十季盤口。
- [JBot 台灣運彩 API](https://sportsbot.tech/api/sportslottery/)：有實作私有端點解析，但現無已授權的排程金鑰。
- [官方 NBA 傷病](https://official.nba.com/nba-injury-report-2026-27-season/)：高優先的人工／未來結構化驗證來源。

**原則：** 先有真實數據、時間與來源，再有模型；數據缺失就拒絕或降低信心。多爬幾個網站不等於資訊更正確。
