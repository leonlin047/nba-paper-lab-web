# CPU 樹模型候選版：部署規格與驗證

這次新增 Elo 基準加 LightGBM 修正的公開候選模型，保留 Elo 主模型、既有整數因子與陣容觀測。沒有匯入私人 APEX 的程式、係數或第三方未公開模型，也沒有宣稱超越 MySports。手機使用者直接開啟平台，運算由現有 GitHub Actions 排程執行，不需自備電腦或 GPU。免費服務仍受供應商額度限制。

## 模型與資料邊界

- 20 個明確列名的比分、休息、賽程、近況與月份特徵。每場特徵只使用較早台北比賽日的賽果，同一天的結果不入模。
- 勝負：以 Elo 的 log-odds 為初始分數，訓練 CPU LightGBM 修正，再以分離校準期擬合正斜率 Platt 校準。LightGBM 的序列化模型不含 Dataset 初始分數，推論時明確加回 Elo。
- 分差、總分：分別訓練對既有比分基準的殘差樹，較晚驗證期選修正幅度，另一個更晚校準期估平均偏差及誤差分布。
- 比較基準也使用相同校準期另行校準；同場、同子集比較，另外保留原始未校準 Elo 指標。
- 實際讓分／總分線僅採同 event、日期、主客隊、預測前六小時內取得的報價。沒有報價只顯示模型淨勝與總分，不造盤口。整數盤含走盤機率，半分盤不含走盤；四分之一盤不支援。
- 過盤及大小機率來自比分校準誤差的經驗分布，尚非歷史盤口專用校準，不能把比分誤差改善直接說成過盤勝率改善。
- 陣容、球員能力損失、替補能力與技術對位目前缺少跨季具時間戳資料，仍未加入訓練。可核對的主要輪替傷停可阻止列入勝負精選，但不直接調分。這是保守品質條件，效果尚未驗證。

## 歷史開發結果

依賽季結束年分期：2019–2023 訓練，2024 選規格／幅度，2025 校準，2026 測試 1,316 場。2026 已用於先前研究，因此這是開發重播，不是全新外部驗證。

| 指標 | 候選 | 同條件校準基準 | 原始基準 |
|---|---:|---:|---:|
| 獨贏相符 | 890/1,316 | 886/1,316 | 879/1,316 |
| 勝率 Brier（越低越好） | 0.21008 | 0.21043 | 0.21125 |
| 分差 MAE | 11.647 | 11.712 | 11.715 |
| 總分 MAE | 15.368 | 15.517 | 15.507 |

按台北比賽日成組重抽樣 300 次的改善 95% 區間：勝率 Brier −0.00187 至 +0.00260；分差 MAE +0.028 至 +0.103 分；總分 MAE +0.024 至 +0.274 分。正數代表候選誤差較小。獨贏改善區間跨零，不能認定穩定勝出；比分有小幅開發期改善，仍需真正前瞻驗證。

較早校準期以信心第60百分位預設約40%覆蓋；測試實際選 540/1,316（41.0%）場，相符 415/540（76.9%），**同一子集基準也為415/540**。沒有用測試賽果挑達成某個命中率的門檻。這個數字不能代表全部場次，也不可直接與另一平台不同期間、盤口、覆蓋率的「79%」相比。

## 真正前瞻封存與手機頁面

`gbdt-pregame-ledger.json` 只接收當下距開賽1至24小時、賽程快照不超過六小時的首次預測；每個 event 僅收一次，模型週更也不覆寫、不重複計場。發布時尚未完賽的場次維持待賽，賽後核對同 event、日期、主客隊及有效終場比分。走盤另計，缺盤口不算輸或贏。真實成績不由歷史回測補填。

「賽事中心 → CPU 樹模型」顯示全部賽前估計、中文報告、勝負精選標記及分差／總分90%結果參考區間；勝負精選不套用至讓分與大小分。「預測成績 → CPU 樹模型」按日期與市場核對全部首次封存，另外顯示精選組及同場有去水市場機率的 paired Brier。首次發布沒有任何已結算樣本，不能先報真實命中率。

整數因子的成績頁同時修正為真正前瞻紀錄優先、可按日期與市場篩選；歷史回測與舊盤口重播在獨立展開區塊，避免混入每日實績。既有四個主導覽與品牌開場保留。

## 記憶、成本與更新

- `gbdt-result-history.json` 累積已收錄終場比分、首次觀測時間及更正時間，避免賽程移出14日視窗後遺失已收錄事實。同 event 同身分的來源比分更正可更新；衝突主客隊或日期不合併。
- 未變的已用樣本雜湊與模型程式版本相符時，同週直接沿用模型與校準快取；新一週有新賽果才重訓。程式更動、已用標籤／特徵更正或遺失會重新驗證與訓練。
- 開發回測另有輸入／程式雜湊快取。必要的時序重播和完整性檢查仍會執行；「舊樣本重訓0」不代表完全不讀舊資料。
- Actions 每週模型快取沿用，不每小時新增一份大快取。快取遭服務淘汰時可由已存資料重建。免費額度、資料服務可用性與商用再散布權尚非保證。
- 單CPU執行、固定種子、依賴版本鎖定。中文報告為資料模板，不逐場呼叫付費LLM，因此不增加逐場推論 token 成本。
- 模型與校準物件留在工作流程快取，公開頁面只存預測、方法與稽核資料；這不表示公開儲存庫的 Actions 快取具有商業保密保證。不得把秘密放進快取。
- 這是受控定期重訓與驗證，並非具備自行研究、改寫程式與自動升級的通用智能。`automatic_promotion=false`，Elo 不自動被取代。

## 驗證與入口

新增測試涵蓋特徵不讀標籤、同日分期拒絕、模型初始分數序列化、校準資料邊界、各目標固定規格、機率與走盤、報價時序與身分、陣容快照、首次封存、結算、比分記憶與週快取／資料更正。完整離線測試與 JavaScript 語法檢查通過後才發布。
