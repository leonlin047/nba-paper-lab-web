## 因子與權重

每場重新計分；正分支持主隊或大分，負分支持客隊或小分。每項權重為 −2 至 +2 的整數，訓練集座標搜尋選擇，含稀疏懲罰；尺度只用後一年驗證集挑選。沒有用測試標籤選權重。這是受文獻啟發的簡化評分卡，不是完整重現 RiskSLIM，也不宣稱全域最優解。

| 因子 | 條件／門檻 | 勝負權重 | 分差權重 | 總分權重 |
|---|---|---:|---:|---:|
| 休息間隔差 | 主隊≥48小時、客隊≤30小時為+1；相反−1，其他0 | +2 | +2 | — |
| 近七日賽程密度 | 客隊比主隊多≥2場為+1，少≥2場−1 | 0 | 0 | — |
| 超出 Elo 的近期表現 | 近5場 Elo 分差殘差，收縮後主客差≥2／≤−2 | 0 | 0 | — |
| 近期比分相對實力 | form margin − Elo margin ≥3／≤−3 | 0 | −1 | — |
| 兩隊近期總分 | 近5場兩隊總分均值偏離基準≥4／≤−4 | — | — | +1 |
| 聯盟總分變化 | 近20場相對近100場總分差≥3／≤−3 | — | — | +1 |
| 兩隊背靠背 | 最近場均距本場≤30小時 | — | — | 0 |

休息與密集賽程同屬疲勞組，合計最多 ±2 分。未知值與已確認的零分分開保存。零權重代表此訓練程序沒有選用。勝率以 log-odds 加總（尺度0.2），分差／總分每分尺度2；計分不是直接的籃球比分。整數盤另估走盤區間，三種機率合計為1；分布機率仍未完成盤口校準。

## 前瞻與避免重跑

首發快照 55 場真正開賽前預測，0 場已結算。只有距開賽至少60分鐘，才把該 event_id／model_version 的第一次輸出鎖定；後續不覆寫，賽後排程核對勝負、讓分與大小。模型今日最新估計與首次封存可能不同，正式前瞻成績以首次封存為準。檔案於開賽前提交至公開 Git 歷史可供核對。

模型程式、依賴、歷史資料與 Python 主次版本指紋相同時重用訓練快取；已連跑兩次確認舊樣本重訓0、沒有新增重複封存。必要的歷史時序掃描仍會執行，不能等同完全不處理舊資料。已有每小時排程接上計分更新、快取與封存，沒有另加高頻排程。無自動升級冠軍／自主修改自身程式；新賽果累積與自動核對不等同已證明自主進化。

## 已修復與仍有的限制

- 開場不再因 sessionStorage 隱藏或短時間自動跳過，頁首可重播；減少動態使用者仍能看封面。
- 缺盤場次增加公開 ESPN core odds 備援，近48小時最多12場、每場最多2個來源物件、55分鐘快取。只允許同一官方來源及相同賽事路徑，不繞過登入或付費。
- 實查 11 場缺盤的10月29日賽事，備援均回空報價。無法藉程式製造尚未公布的資料；介面改列模型淨勝與總分、待實際盤口。
- 台灣公開盤口本次來源4場取得、4場匹配，但不代表所有未來賽事完整或取得商業授權。資料來源再發布與收費使用權仍待確認，不能用移除標籤假裝解決。
- 傷停、球員影響、旅行與時差等缺乏完整歷史時點資料，仍留在描述層，尚未量化權重。
- APEX 與融合仍缺獲准公開的真實前瞻樣本，不用因子或 Elo 的數字冒充。
