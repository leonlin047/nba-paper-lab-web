# 墨場 COURT NOIR

中文名「墨場」結合閱讀與籃球場；英文 COURT NOIR 延伸黑色裁縫、沉穩與街頭球場的氣質。這是本次創作的品牌提案，尚未做商標或名稱權利檢索。

視覺：墨黑 `#242422`、紙白 `#F4F1EB`、銅色 `#BB7957`。以球場邊線、禁區弧線、西裝領口與領帶構成極簡圖形，避免槍械或暴力符號。圖示與人物均為自行繪製 SVG；中文字標以 Noto Serif CJK TC 轉成向量輪廓，英文字標以 DejaVu Sans 轉為輪廓，網站執行時不下載字型，也沒有照片追蹤或外部圖像依賴。字型來源：https://github.com/notofonts/noto-cjk 與 https://dejavu-fonts.github.io/。

開場：五位英式平頂帽、黑西裝人物，拿著書本與籃球，分層進場，配上「以球入場，以書立身」。使用 SVG 與 CSS，約 3.4 秒，無音效、無影音自動播放、無動畫套件。

首次同一瀏覽器分頁工作階段播放；可跳過、按 Escape、在「關於平台」重播。尊重系統減少動態設定；資料載入與動畫互相獨立，資產失敗也會按時解除遮罩。未開啟 JavaScript 時不顯示遮罩。
